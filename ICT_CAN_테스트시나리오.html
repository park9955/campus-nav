🧭 ICT CAN 테스트 시나리오

ICT폴리텍대학 자원 내비게이션 시스템 | 공급자: 시스템 | 이용자: 5명
TEST 1 학부생
순작업기대 결과
1학부생 버튼 클릭로그인 창 나타남
2아이디/비밀번호 입력 → 로그인학부생 홈 화면 열림
3자원 수 확인8,401개 보임
4자원 검색 메뉴 클릭자원 목록 나타남 (20개씩)
5검색어 입력 또는 분류 선택조건에 맞는 자원만 보임
6자원 클릭상세정보·지도·이전 기록·신청 폼 보임
7신청 폼 입력 → 신청신청 완료 또는 중복 경고
8자원 옮긴 기록 메뉴옮긴 자원 목록 보임
9로그아웃 클릭로그인 화면으로 돌아감
TEST 2 조교
순작업기대 결과
1조교 버튼 클릭 → 로그인조교 홈 화면 열림
2자원 검색·분류·신청 (학부생과 동일)잘 작동함
3교수 정보 메뉴 클릭교수 카드 목록 (담당 과목·스킬 보임)
4교수 카드 선택 → 정보 수정과목/스킬 추가·삭제 가능
5자원 옮긴 기록 메뉴옮긴 목록 및 옮기기 기능
6로그아웃로그인 화면으로 돌아감
TEST 3 교수
순작업기대 결과
1교수 버튼 클릭 → 로그인교수 홈 화면 열림
2자원 검색·분류·신청 (학부생과 동일)잘 작동함
3내 정보 메뉴 클릭담당 과목·스킬 정보 보임
4정보 수정 → 과목/스킬 입력 → 저장과목/스킬 추가·삭제되고 저장됨
5자원 옮긴 기록 메뉴옮긴 자원 목록 보임
6로그아웃로그인 화면으로 돌아감
TEST 4 관리자
순작업기대 결과
1관리자 버튼 클릭 → 로그인관리자 홈 화면 열림
2자원 관리 메뉴자원 목록 (8,401개), 추가/수정/삭제 버튼
3추가 → 정보 입력 → 저장새 자원이 목록에 추가됨
4자원 선택 → 수정 → 정보 변경 → 저장변경사항이 바로 반영됨
5자원 선택 → 삭제 → 확인자원이 목록에서 지워짐
6상태/분류로 검색조건에 맞는 자원만 보임
7로그아웃로그인 화면으로 돌아감
TEST 5 외부인
순작업기대 결과
1외부인 버튼 클릭사용 안내 팝업 보임
2외부인으로 입장 클릭로그인 없이 들어가짐
3공간 예약 → 정보 입력 → 신청예약 완료됨
4길찾기 메뉴지도·길찾기 기능
5자원 검색 클릭 시도사용 불가 메시지
6자원 상세 직접 접근접근 차단 안내
7로그인 화면으로 돌아가기로그인 화면 나타남
