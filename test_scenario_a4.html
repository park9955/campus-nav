🧭 ICT CAN 테스트 시나리오

ICT폴리텍대학 교내 자원 내비게이션 시스템 — 사용자 행동 테스트
📋 테스트 개요
공급자(시스템)는 5가지 사용자 역할을 지원합니다. 각 사용자는 로그인 후 자신의 권한에 맞는 기능을 이용할 수 있습니다.
사용자 테스트 시나리오 (각 단계별 실행)
학부생
1학부생 버튼 선택 → 테스트 아이디/비밀번호 입력 → 로그인
2대시보드: 등록자원 수 확인
3자원 검색 페이지에서 키워드/카테고리로 검색 후 페이징
4자원 상세보기 → 예약 기능 테스트 (중복 예약 불가 확인)
5자원 이전 내역 조회 → 로그아웃
조교
1조교 버튼 선택 → 로그인
2자원 검색 및 상세보기 (학부생과 동일)
3자원 예약 및 이전 기능 테스트
4교수 정보 조회 (담당 과목/스킬 확인)
5로그아웃
교수
1교수 버튼 선택 → 로그인
2자원 검색 및 예약 테스트
3내 정보 조회: 담당 과목/스킬 태그 확인
4자원 이전 기능 이용
5로그아웃
관리자
1관리자 버튼 선택 → 로그인
2자원 관리 페이지 접근 (추가/수정/삭제 권한 확인)
3자원 검색 및 필터링 기능 검증
4사용자 예약/이전 기록 조회
5로그아웃
외부인
1외부인 버튼 선택 → 계정 없이 입장
2✓ 가능: 공간 예약, 캠퍼스 길찾기 이용
3✗ 제한: 자원 검색, 자산 상세 조회 불가 확인
4외부인 페이지에서 사용 가능/불가 안내문 표시 확인
5재학생·교직원 로그인 화면으로 돌아가기
✅ 모든 사용자가 확인해야 할 기본 검증 사항:
✓ 로그인/로그아웃 정상 작동
✓ 역할별 권한 제어 (버튼 표시/숨김)
✓ 검색 기능 (키워드/카테고리/상태)
✓ 페이징 (20개씩 표시)
✓ 예약 및 중복 방지 (AJAX 검증)
✓ 자원 이전 이력 조회
