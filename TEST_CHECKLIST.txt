[TEST 1] 학부생 (Student) 테스트
================================================================================

  ├─ □ "학부생" 버튼 클릭 가능

  ├─ □ 검색 결과에서 자원 클릭
  ├─ □ 자원 상세 정보 표시

  ├─ □ 예약 상태 표시
  └─ □ 이전 이력 타임라인 표시

□ 1-5. 예약 기능
  ├─ □ 예약하기 버튼 클릭

  ├─ □ 예약 가능 상태일 때 신청 버튼 활성화
  ├─ □ 신청 버튼 클릭
  └─ □ 예약 완료 메시지 표시

□ 1-6. 자원 이전 조회
  ├─ □ 자원 이전 메뉴 클릭
  ├─ □ 이전 이력 목록 표시
  ├─ □ 이전 기록 상세보기 가능
  └─ □ 이전 기록 페이징 정상

□ 1-7. 로그아웃
  ├─ □ 로그아웃 버튼 클릭

[종합 점검 사항] - 모든 사용자가 테스트해야 할 항목
================================================================================

□ 로그인/로그아웃
  ├─ □ 로그인 성공 시 올바른 역할의 페이지로 이동
  ├─ □ 로그아웃 후 로그인 페이지로 돌아감
  ├─ □ 세션이 정상 종료됨 (재접속 시 로그인 필요)
  └─ □ 빈 아이디/비밀번호로 로그인 불가

□ 권한 제어 (Authorization)
  ├─ □ 학부생이 관리자 메뉴 접근 불가
  ├─ □ 조교가 관리자 메뉴 접근 불가
  ├─ □ 외부인이 제한 기능 접근 불가
  ├─ □ 각 역할에 맞는 기능만 표시됨
  └─ □ 세션이 없을 때 로그인 페이지로 리디렉션됨

□ 검색 기능
  ├─ □ 빈 검색어로도 전체 목록 표시 (또는 "검색어 입력" 메시지)
  ├─ □ 한글 검색 정상 작동
  ├─ □ 영문 검색 정상 작동
  ├─ □ 숫자 검색 정상 작동
  ├─ □ 검색 결과 없을 때 "검색 결과 없음" 메시지 표시
  └─ □ 대소문자 구분 없이 검색됨

□ 필터링/카테고리
  ├─ □ 카테고리 선택 시 해당 자원만 표시
  ├─ □ 상태 필터(사용중/사용가능/대여중) 정상 작동
  ├─ □ 복합 필터 적용 가능
  ├─ □ 필터 해제 시 전체 목록 표시
  └─ □ 필터 적용 상태가 UI에 표시됨

□ 페이징
  ├─ □ 한 페이지에 정확히 20개씩 표시
  ├─ □ 페이지 번호 표시됨
  ├─ □ "이전" 버튼이 첫 페이지에서 비활성화됨
  ├─ □ "다음" 버튼이 마지막 페이지에서 비활성화됨
  ├─ □ 페이지 이동 시 URL이 변경됨
  └─ □ 페이지 새로고침 후에도 같은 페이지 표시

□ 예약 기능
  ├─ □ 예약 폼이 명확하게 표시됨
  ├─ □ 필수 필드는 별 또는 텍스트로 표시
  ├─ □ 실시간 중복 예약 검증 (AJAX)
  ├─ □ 중복 예약 불가 메시지가 명확함
  ├─ □ 같은 자원을 여러 번 예약 시도 시 경고
  ├─ □ 예약 가능할 때만 신청 버튼 활성화
  ├─ □ 신청 후 확인 메시지 표시
  └─ □ 예약 내역이 대시보드에 반영됨

□ 에러 처리
  ├─ □ 데이터베이스 오류 시 사용자 친화적 메시지 표시
  ├─ □ 필수 입력값 누락 시 명확한 에러 메시지
  ├─ □ 권한 없는 접근 시 403 또는 명확한 거부 메시지
  ├─ □ 데이터 없을 때 "데이터가 없습니다" 메시지
  ├─ □ 서버 오류 시 에러 로그 기록 (개발자 확인용)
  └─ □ 에러 메시지가 기술적이지 않고 이해하기 쉬움

□ 사용자 인터페이스 (UI/UX)
  ├─ □ 모든 버튼이 클릭 가능하고 반응 있음
  ├─ □ 입력 필드가 Focus 될 때 스타일 변경 (파란색 테두리 등)
  ├─ □ 주요 액션 버튼 (로그인, 신청 등)이 눈에 띔
  ├─ □ 각 페이지에 뒤로가기 또는 홈 버튼 있음
  ├─ □ 네비게이션 메뉴가 항상 접근 가능
  ├─ □ 화면 로딩 중에는 로딩 표시 (스피너 등)
  ├─ □ 텍스트가 명확하고 읽기 쉬움 (폰트 크기 충분)
  └─ □ 색상이 일관되고 전문적임

□ 반응형 디자인 (모바일/태블릿/PC)
  ├─ □ PC (1920x1080)에서 정상 표시
  ├─ □ 태블릿 (768px)에서 정상 표시 및 터치 가능
  ├─ □ 모바일 (375px)에서 정상 표시 및 터치 가능
  ├─ □ 네비게이션 메뉴가 모바일에서 해메뉴로 표시
  └─ □ 테이블/리스트가 모바일에서도 보기 좋게 정렬됨

□ 성능
  ├─ □ 페이지 로드 시간이 3초 이내
  ├─ □ 검색 결과가 1초 이내에 표시
  ├─ □ 예약 중복 확인이 실시간으로 작동 (0.5초 이내)
