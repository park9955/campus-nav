## 1. UI/UX 설계 개요

### 1.1 설계 목표
- 직관적이고 사용하기 쉬운 인터페이스
- 5분 내에 기본 사용 가능
- 모든 역할에 맞춤형 경험 제공
- 접근성 표준 준수 (WCAG 2.1 AA)

### 1.2 설계 원칙

```
1. 사용자 중심 설계 (User-Centered Design)
   - 6개 역할별 요구사항 분석
   - 사용자 페르소나 기반 설계
   - 테스트 기반 반복 개선

2. 단순성 (Simplicity)
   - 필수 기능만 노출
   - 불필요한 옵션 숨김 (Advanced는 선택)
   - 명확한 CTA (Call-to-Action)

3. 일관성 (Consistency)
   - 동일한 스타일 가이드
   - 버튼, 색상, 타이포그래피 통일
   - 같은 작업은 같은 방식

4. 피드백 (Feedback)
   - 모든 작업 후 피드백 (성공/실패)
   - 로딩 상태 표시
   - 진행 상황 안내

5. 접근성 (Accessibility)
   - WCAG 2.1 AA 준수
   - 키보드 네비게이션
   - 스크린 리더 지원
   - 색상 대비 >= 4.5:1
```

## 2. 디자인 원칙 및 가이드

### 2.1 색상 팔레트

```
Primary Color (주색)
├─ #007BFF (파란색) - 주요 버튼, 링크
└─ 사용처: CTA, 강조 요소

Secondary Color (보조색)
├─ #6C757D (회색) - 보조 버튼
└─ 사용처: 부가 버튼, 텍스트

Status Colors (상태색)
├─ #28A745 (초록색) - 성공, 사용 가능
├─ #FFC107 (노랑색) - 경고, 예약됨
├─ #DC3545 (빨강색) - 오류, 정지됨
└─ #6C757D (회색) - 비활성, 폐기됨

Text Color
├─ #212529 (진회색) - 본문
├─ #495057 (회색) - 보조 텍스트
└─ #FFFFFF (흰색) - 역색상

Background
├─ #FFFFFF (흰색) - 기본 배경
├─ #F8F9FA (연회색) - 섹션 배경
└─ #E9ECEF (옅은 회색) - 비활성 영역
```

### 2.2 타이포그래피

```
Font Family: "Segoe UI", "Malgun Gothic", Arial, sans-serif

Heading Hierarchy:
├─ H1: 32px, Bold, 페이지 제목
├─ H2: 24px, Bold, 섹션 제목
├─ H3: 18px, Bold, 하위 섹션
├─ H4: 16px, Semi-bold, 항목 제목
└─ Body: 14px, Regular, 본문

Line Height: 1.5 (본문), 1.2 (제목)
Letter Spacing: -0.02em (제목), 0 (본문)
```

### 2.3 간격 및 크기

```
Spacing Scale (8px 기반):
├─ xs: 4px (최소 간격)
├─ sm: 8px (작은 간격)
├─ md: 16px (기본 간격)
├─ lg: 24px (큰 간격)
├─ xl: 32px (매우 큰 간격)
└─ 2xl: 48px (최대 간격)

Button Size:
├─ Small: 32px height, 8px horizontal padding
├─ Medium (기본): 40px height, 16px horizontal padding
└─ Large: 48px height, 24px horizontal padding

Input Height: 40px (표준)
Border Radius: 4px (표준)
```

## 5. 사용자 인터페이스 요소

### 5.1 버튼 스타일

```
Primary Button (주요 작업):
┌────────────────┐
│  ✓ 로그인      │ (파란색 배경, 흰색 텍스트)
└────────────────┘
사용처: 로그인, 예약, 저장, 완료

Secondary Button (부가 작업):
┌────────────────┐
│  ○ 취소        │ (회색 배경, 검정 텍스트)
└────────────────┘
사용처: 취소, 돌아가기, 닫기

Danger Button (위험한 작업):
┌────────────────┐
│  ✗ 삭제        │ (빨간색 배경, 흰색 텍스트)
└────────────────┘
사용처: 삭제, 폐기
```

## 8. 접근성 및 포용성

### 8.1 WCAG 2.1 AA 준수

```
시각적 접근성:
├─ 색상 대비: 4.5:1 (일반 텍스트), 3:1 (큰 텍스트)
├─ 텍스트 크기: 최소 12px
├─ 초점 표시: 명확한 outline (2px 파란색)
└─ 글꼴: sans-serif (읽기 쉬움)

청각 접근성:
├─ 비디오에 자막 (향후)
├─ 오디오에 대본 (향후)
└─ 시각적 알림 (소리 대신)

운동성 접근성:
├─ 키보드만으로 모든 기능 사용 가능
├─ Tab 키로 네비게이션
├─ Enter로 버튼 활성화
├─ 화면 확대 200% 지원
└─ 터치 대상 최소 48x48px

인지 접근성:
├─ 명확한 언어 사용
├─ 일관된 네비게이션
├─ 에러 메시지는 구체적
└─ 진행 상황 표시
```
